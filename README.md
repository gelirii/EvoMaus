# EvoMaus

Mobile-first browser evolution game for GitHub Pages.

The playable v1 site lives on the `gh-pages` branch so GitHub Pages can serve it directly from the repository root.

## v1

- 256 × 256 canvas maze editor
- wall, cheese, danger, goal and eraser tools
- draggable mouse start point
- pinch zoom and two-finger pan
- configurable mouse population
- genetic evolution using selection, crossover, mutation, elitism and random immigrants
- safe-route flood-fill fitness scoring
- camera follows the previous generation champion lineage
- pause, speed, edit and reset controls
- maze saved locally in the browser
